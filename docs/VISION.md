# Lumen Run Vision

## Core Identity
Lumen Run is a one-touch sci-fi orbit runner about carrying a fading Relay Core through a collapsing orbital signal network.

Lumen is the scattered signal energy the player recovers. The player is the Relay Core. Glitch is the corruption breaking the network.

## Player Promise
- The player always feels that survival depends on control, timing, and pattern reading rather than luck.
- Relays should become more intense over time through speed, obstacle patterns, Oversync states, and escalating rewards.
- Audio, visual effects, title screen, items, and feedback should feel like one unified game world.

## Design Pillars
- Simple controls, deep mastery
- Fair obstacle readability
- Fast restart and strong relay-to-relay momentum
- Clear audiovisual feedback
- App Store-ready polish
